# Employee Leave Management System

## Project Overview
The Employee Leave Management System is a console-based Java application designed to manage employee information and leave requests.

## Features
- Manage employee information
- Support permanent and contract employees
- Submit and manage leave requests
- Validate leave requests
- Handle custom exceptions

## Technologies Used
- Java
- Core Java
- Object-Oriented Programming (OOP)
- Java Collections
- Exception Handling

## Project Structure
`src/Assignment1/EmployeeLeaveManagementSystem.java`

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Java project.
3. Open `EmployeeLeaveManagementSystem.java`.
4. Run the class as a Java Application.
